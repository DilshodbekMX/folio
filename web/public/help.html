Folio

User guide

Folio is a self-hosted editor for writing LaTeX together: the source on one side, the typeset PDF on the other, and everyone’s edits in real time.

Projects

Your project list shows everything you own or that was shared with you. Use New project to start from a blank article, from an example (sections, maths, a figure, a table and citations), or by uploading a .zip of an existing project.

  • Archive and Trash only change your own list; collaborators are not affected.
  • Only the owner can delete a project for good, from the trash. Collaborators can Leave a trashed project instead.
  • Make a copy copies the files; collaborators, share links, history and chat stay with the original.

When you upload a zip, a single top-level folder is unwrapped, build output such as .aux, .log and .synctex.gz is skipped, and the main document is the .tex file containing \documentclass (preferring main.tex).

The editor

The top bar holds the menus (File, Edit, Insert, View, Format, Help), the project name (click it to rename), the people who are online (click an avatar to open the file they are in), History, Share and Layout. The rail on the left switches between the file tree, project search and chat; settings and help are at the bottom.

Drag the dividers to resize panes. Layout switches between split view, editor only and PDF only; the arrow tab at the edge brings the other pane back.

Compiling

Press Recompile, or Ctrl+Enter / Ctrl+S (⌘ on a Mac). With auto compile on, Folio recompiles a couple of seconds after you stop typing. Every compile includes your last keystroke.

  • Compiler (pdfLaTeX, LaTeX, XeLaTeX, LuaLaTeX), the main document and the timeout are project settings shared by all editors (Settings → Compiler).
  • Fast [draft] skips images; Stop on first error halts at the first LaTeX error.
  • Recompile from scratch and Clear cached files remove auxiliary files when a stale .aux causes strange errors.
  • Documents that use xr’s \externaldocument are built in the right order automatically.

The logs pane lists errors, warnings and bad boxes with the file and line; Go to code location opens the source there.

Source ↔ PDF

The two arrows on the divider between the editor and the PDF jump between them: → highlights where the line under your cursor appears in the PDF, ← moves the cursor to the source of the PDF location. Double-clicking a word in the PDF is the most precise way to jump to its source.

Files

Create files and folders, upload files or whole folders (drag them onto the tree), rename with F2 or a double-click, and drag items to move them. Right-click a .tex file and choose Set as main document to compile it by default. Images, PDFs and EPS files open in a preview.

Collaborating

Share lets the owner add people by email as editors (who can change everything except sharing) or viewers (who can read, see the PDF and follow the history, but not edit). Link sharing creates an editor link and a view-only link; anyone who opens one after logging in can join with that role. Regenerating or turning off a link stops it from working.

Everyone’s cursors and edits appear live. Undo only undoes your own changes. The chat panel keeps a conversation per project.

History

Folio saves versions automatically while you work. Open History to browse versions by day, see what changed in each file, compare two versions, label important versions, download a version as a .zip, and restore a single file or the whole project. Restoring never discards anything: it adds a new version.

Running a server

The first person to open a new Folio server creates the administrator account. Administrators add and remove users from the admin page. Without email, passwords are reset from the command line on the server:

npm run create-user -- --email ada@example.com --name "Ada Rivera" --password '…' [--admin]
npm run reset-password -- --email ada@example.com --password '…'
npm run doctor

Compiles run in a sandboxed TeX Live container without network access. npm run doctor checks Docker, the TeX image, git and the data directory.
